# 퇴고의 제왕

**한 눈에 개정본 보고 원하는 부분만 합치기** 심너울이 만든 원고 비교 도구, 버전 1.0.

HWP·HWPX 원문과 개고본을 나란히 읽고, 바뀐 문단마다 원문 유지 또는 개고 채택을 선택합니다. 선택하면 양쪽 문단이 선택한 본문으로 바뀌고 변경 강조가 사라집니다. 선택 해제와 되돌리기도 가능합니다.

## 사용

1. ‘사용’에서 원문과 개고본을 하나씩 선택합니다. ‘예제로 비교하기’를 누르면 심너울의 「한 쪽이 너무 유리한 게임」 원문과 시연용 개고안을 바로 엽니다.
2. 바뀐 글자만 빨강·초록으로 강조합니다. 문단마다 문구 수정, 문장 교체, 문장 나눔·합침과 전후 문장 수를 표시합니다.
3. 바뀐 **문단 단위**로 원문 유지 또는 개고 채택을 선택합니다. 미선택 문단은 원문으로 저장합니다.
4. 선택한 원고를 새 파일로 저장합니다. **두 파일 모두 HWP이면 HWP, 하나라도 HWPX이면 HWPX**입니다. TXT 저장도 가능합니다.

장면은 **Enter 두 번 — 문단 사이의 빈 줄 하나**로 구분합니다. 빈 문단이 여러 개 연속되어도 장면 경계 하나로 봅니다. Shift + Enter나 문단 여백은 장면 경계가 아닙니다.

Alt + ←/→로 장면, Alt + ↑/↓로 변경 문단을 이동합니다. 검토 선택은 같은 브라우저에 자동 저장되며 ‘선택 백업 / 불러오기’로 옮길 수 있습니다. 본문은 저장하지 않으므로 원고 파일은 별도로 보관해야 합니다. 쿠키가 아닌 `localStorage`에 파일 이름, 문단별 선택, 마지막 장면과 저장 시각을 기록합니다. 메인 화면의 ‘이 브라우저에 저장된 비교’에서 기록을 고르고 같은 원문·개고본을 다시 선택하면 이어갈 수 있습니다. 예제 기록은 바로 다시 열립니다. 이전 버전의 기록은 이름·시각 정보 없이도 표시하며, 같은 파일을 다시 열면 정보가 채워집니다. 기록은 같은 사이트 주소와 같은 브라우저에만 남습니다.

로고나 ‘다른 원고 비교’로 메인에 돌아갈 때 현재 선택으로 원고를 내려받지 않았다면 저장 여부를 묻습니다. 저장 후 선택을 바꾸면 다시 확인합니다. 내려받기 요청을 기준으로 판단하므로 브라우저에서 다운로드를 취소했다면 다시 저장하세요.

## 직접 편집하고 다시 합치기

- ‘개고본 직접 편집’에서 현재 개고본 전체를 고칠 수 있습니다.
- ‘합친 원고 편집’에서 현재 선택 결과를 합친 글을 고칠 수 있습니다. 미선택 문단은 원문으로 들어갑니다.
- ‘개고본에 적용하고 다시 비교’를 누르면 원문은 유지하고 수정한 글을 새 개고본으로 사용합니다. 내용이 그대로인 문단의 선택은 유지하며, 새로 고친 부분은 다시 검토합니다.
- Enter는 문단, Enter 두 번은 장면 구분, Shift + Enter는 문단 안 줄바꿈입니다.
- ‘개고본 저장’은 수정한 개고본 전체를, 기존 원고 저장은 선택해서 합친 결과를 내려받습니다. **직접 쓴 글은 브라우저 기록에 영구 보관되지 않습니다.** 나중에 이어가려면 새 개고본을 내려받아 원문과 함께 보관하세요.

## 지원 범위

- HWP 5와 HWPX 본문. HWP 3, 암호·DRM·배포용 보호 문서는 지원하지 않습니다.
- 파일 하나당 30 MB, 본문 100만 자, 4만 문단. 변경이 매우 많은 큰 원고는 부별 비교를 권합니다.
- 본문과 빈 문단을 A4 기본 서식의 새 문서로 저장합니다. 원본의 글꼴·쪽 배치·표 모양·그림을 재현하지 않습니다.
- 표·글상자·주석은 저장된 순서로 펼쳐 읽습니다. 복잡한 배치나 한글의 변경 추적 검토 중인 원고는 본문만 정리하거나 변경을 확정한 사본을 준비해 주세요.
- 원고 파일 읽기, 비교, 합치기, 파일 생성은 모두 브라우저 내부에서 수행합니다. 서버, API 키, 회원가입, 분석 추적, 외부 폰트가 없습니다. 예제 파일만 사이트에서 불러옵니다.

## 개발과 GitHub Pages

Node.js 24에서 실행합니다.

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
```

`dist/`가 완성된 정적 사이트입니다. GitHub 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 선택하세요. `main`에 변경을 올리면 포함된 Pages 작업이 테스트, 빌드, 배포를 실행합니다. 프로젝트 하위 주소에서도 동작하도록 상대 경로를 사용합니다.

`npm run examples`는 예제 TXT에서 HWPX 파일을 다시 생성합니다. 원고 다운로드 링크는 화면에 두지 않으며, 예제 버튼은 준비된 HWPX 두 파일을 직접 읽습니다.
