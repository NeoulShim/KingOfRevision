# 비교 예제

심너울의 「한 쪽이 너무 유리한 게임」을 저자 허락으로 수록했습니다.

- 원문: 제공된 HWP에서 추출한 본문과 빈 문단을 보존했습니다. 본문 14,793자, 162문단.
- 개고안: 사건, 인물 관계, 반전을 유지하며 문장 호흡과 반복 표현을 다듬은 시연용 제안입니다. 본문 14,274자, 162문단. 줄바꿈을 제외한 수치입니다.
- 제목과 ‘끝’도 원문대로 보존했기 때문에 빈 문단 기준으로 8개 구간으로 표시됩니다. 처음에는 변경이 있는 본문부터 보여줍니다.
- 예제 버튼은 `public/examples/`의 실제 HWPX 두 파일을 읽습니다. 별도 예제 다운로드 화면은 없습니다.

체스 설명은 스테일메이트의 조건, 랜덤 체스 배치, 자기 말을 먼저 잃는 변형의 승리 조건, 변형 체스의 연대 설명을 정돈했습니다. 문장 나눔·합침과 문장 교체를 포함해 문단별 비교를 체험할 수 있습니다.

확인 자료: [FIDE 체스 규칙](https://handbook.fide.com/chapter/E012023), [Chess960](https://lichess.org/variant/chess960), [Antichess](https://lichess.org/variant/antichess), [Atomic](https://lichess.org/variant/atomic).
